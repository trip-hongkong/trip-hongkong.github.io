# HK Trip

날짜, 숙소, 참가자와 이름을 직접 설정할 수 있는 모바일 여행 허브입니다.
초기 참가자는 소준혁과 여자친구이며, 여행 날짜와 숙소는 미정입니다.

## Live site

- https://trip-hongkong.github.io/

## 한 페이지 구성

- 준비: 여행 이름·날짜·지도 설정, 참가자 관리, 개인별 체크리스트, 숙소 추가·수정
- 일정: 날짜별 일정, 날씨, 숙소와 현지 바로가기
- 정산: 참가자별 지출, HKD/KRW 환산, 영수증 사진, 최종 송금액

상단의 준비·일정·정산 탭으로 화면을 전환합니다.

입력한 내용은 브라우저에 저장되며 JSON 백업과 복원이 가능합니다.
공용 여행방에 연결하면 설정·숙소·체크리스트·일정·정산·영수증이 동기화됩니다.
공용 서버가 연결되지 않을 때는 로컬 저장 상태가 표시됩니다.

새 여행 데이터는 로컬 v3 키와 공용 `trip2-` client_id 네임스페이스를 사용합니다.
기존 4인 여행의 로컬 키, 공용 데이터와 영수증은 삭제하지 않습니다.
여행 설정·숙소는 예약된 itinerary metadata records에 저장되어 기존 RLS를 그대로 사용합니다.
날짜를 수정해도 이미 등록한 일정의 날짜나 과거 지출은 자동으로 이동하지 않습니다.
현재 날씨 및 환율은 홍콩과 HKD/KRW 기준입니다.
